# R2 Vault Android APK v1.0

- **Package**: `top.supertato.r2vault`
- **Version**: 1.0 (code 1)
- **Min SDK**: 21 (Android 5.0+)
- **Target SDK**: 34
- **Size**: ~178 KB
- **打开站点**: `https://r2.supertato.top/`（正式域名，非 workers.dev）
- **Signing**: Android debug keystore（仅供个人测试，请勿发布到 Play Store）

## 安装方法

1. APK 使用 debug 签名；手机需开启「允许安装未知来源应用」
2. 把 `R2-Vault-v1.0.apk` 通过微信/QQ/邮件/USB 传到手机
3. 点击 APK 文件 → 允许「此来源」安装
4. 启动 App（图标：R2 Vault）→ 首次需输入访问 Token → 使用

## 注意

- APK 是 TWA（Trusted Web Activity）壳，直接加载 `r2.supertato.top`；需要手机装 Chrome 并保持登录。
- 重建/改域名需要同步更新 `twa-manifest.json` 与 `app/build.gradle` 的 `hostName`，并保证 `r2.supertato.top/.well-known/assetlinks.json` 的 fingerprint 与 APK 签名一致。
