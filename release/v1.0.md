# R2 Vault Android APK v1.0

- **Package**: `top.supertato.r2vault`
- **Version**: 1.0 (code 1)
- **Min SDK**: 21 (Android 5.0)
- **Target SDK**: 34
- **Size**: 178 KB
- **Signing**: Android debug keystore（仅限个人测试，请勿发布到 Play Store）

## 安装方法

1. 手机开启"开发者选项 → USB 调试"和"未知来源应用安装"
2. 把 `R2-Vault-v1.0.apk` 通过微信/QQ/邮件/USB 传到手机
3. 点击 APK 文件安装
4. 安装时浏览器会弹"是否允许此来源安装"→ 允许
5. 启动 App（图标：R2 Vault）→ 输入 token → 使用

## 升级 Worker URL 配置

APK 启动时访问的 URL 硬编码在 `twa-manifest.json` 的 `host` 字段。改 URL 需要：
```bash
cd worker
# 修改 twa-manifest.json 的 host + iconUrl
# 然后重新 build
```
